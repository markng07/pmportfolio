# Mark Duc Nguyen - Portfolio Website

## Overview
A clean, professional portfolio website showcasing Mark Duc Nguyen's product management career and achievements. Built with pure HTML, CSS, and vanilla JavaScript - no build process required.

## Project Structure
- `index.html` - Main portfolio page with all content sections
- `styles.css` - Complete styling with responsive design
- `main.js` - Interactive features (smooth scrolling, animations, mobile menu)
- `server.js` - Simple Node.js HTTP server to serve static files on Replit
- `README.md` - Project documentation

## Tech Stack
- **Frontend**: Pure HTML5, CSS3, Vanilla JavaScript
- **Server**: Node.js HTTP server (for Replit hosting)
- **Deployment**: Configured for Replit environment

## Key Features
- Responsive design (desktop, tablet, mobile)
- Interactive timeline showcasing career journey
- Product portfolio with metrics and achievements
- Animated skill bars and progress indicators
- Smooth scrolling navigation
- Mobile-friendly hamburger menu

## Recent Changes
**2025-11-01**: Initial Replit setup
- Added Node.js HTTP server for static file serving
- Configured server to run on port 5000 with 0.0.0.0 host
- Set up workflow for automatic server startup
- Added cache control headers to prevent caching issues

## Running Locally
The server runs automatically on Replit. For local development:
```bash
node server.js
```
Then visit http://localhost:5000
