## Deployment to GitHub Pages

### Method 1: Direct Upload (Easiest)

1. **Create a new repository** on GitHub (e.g., `portfolio` or `pmportfolio`)

2. **Upload these files** to your repository:
   - `index.html`
   - `styles.css`
   - `main.js`
   - `README.md` (optional)

3. **Enable GitHub Pages**:
   - Go to repository Settings
   - Click on "Pages" in the left sidebar
   - Under "Source", select "main" branch
   - Click "Save"

4. **Your site will be live** at: `https://your-username.github.io/repository-name/`

### Method 2: Git Command Line

```bash
# Initialize git repository
git init

# Add files
git add index.html styles.css main.js README.md

# Commit
git commit -m "Initial commit - Static portfolio"

# Add remote (replace with your repository URL)
git remote add origin https://github.com/your-username/your-repo-name.git

# Push to GitHub
git branch -M main
git push -u origin main
```

Then enable GitHub Pages as described in Method 1, step 3.

### Method 3: GitHub Desktop (User-Friendly)

1. Download and install [GitHub Desktop](https://desktop.github.com/)
2. Open GitHub Desktop and create a new repository
3. Copy your portfolio files into the repository folder
4. Commit the changes in GitHub Desktop
5. Click "Publish repository" to push to GitHub
6. Enable GitHub Pages in your repository settings

## Customization

### Updating Content

Edit `index.html` to change:
- Your name, title, and professional summary
- Experience timeline entries
- Product portfolio items
- Skills and achievements
- Contact information

### Changing Colors

Edit `styles.css` CSS variables at the top:
```css
:root {
    --navy: #0F172A;      /* Main dark color */
    --gold: #D4AF37;      /* Accent color */
    --gray-50: #F8FAFC;   /* Light background */
}
```

### Modifying Behavior

Edit `main.js` to customize:
- Scroll animations
- Navigation behavior
- Interactive effects
